# 📊 Sales Performance Dashboard – Excel

This repository contains an **interactive Sales Dashboard built using Microsoft Excel**.  
The dashboard provides a clear overview of **sales performance, target achievement, and gaps from targets** across multiple cities and sales executives.

---

## 🚀 Project Overview

The purpose of this project is to track and analyze sales performance using Excel dashboards.  
It helps management quickly identify:
- Top-performing sales executives
- Target achievement percentage
- Sales gaps (Away from Target)
- City-wise performance comparison

---

## 📈 Key Metrics & Insights

### 🔹 Total Sales by Sales Executive
- Displays individual sales contribution
- Highlights top and low performers

### 🔹 Target Hit % (Wise)
- Shows how close each executive is to achieving their sales target
- Easy performance comparison

### 🔹 Away From Target %
- Identifies sales gap for each executive
- Useful for corrective planning

### 🔹 City-wise Sales Analysis
- Dashboard supports multiple cities:
  - Chennai
  - Delhi
  - Mumbai
  - Nagpur
  - Patna
  - Pune
  - Ranchi
  - Surat

---

## 🎛️ Dashboard Controls
